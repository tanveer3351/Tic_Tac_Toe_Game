## 📌 About the Project

This project is a browser-based Tic Tac Toe game where two players can play against each other.

Players take turns placing **X** and **O** on a 3×3 game board. The game automatically checks for winning combinations and displays the winner when a player completes a row, column, or diagonal.

If all boxes are filled without a winner, the game ends in a draw.

---

## ✨ Features

* 🎮 Two-player gameplay
* ❌ X and ⭕ O turns
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 🔄 New Game / Reset functionality
* 🚫 Prevents players from selecting an already occupied box
* 💬 Displays the game result
* 📱 Simple and responsive interface
* ⚡ Built with vanilla JavaScript — no frameworks required
